# Pi 官方文档中文版

这里是 Pi 原始文档的中文参考版，不是原创课程的替代品。翻译遵循三个原则：自然中文、保留 API/路径/命令/JSON 字段、遇到实现细节优先回到固定 commit 的源码。

## 如何使用

- 想学习概念和动手实现：从 [基础教材](/01-foundations/llm-to-agent) 开始。
- 想查一个 Pi CLI/API 选项：在下面对应的中文页查找原始文件名。
- 想确认行为：看 [源码索引](/reference/source-map)，再打开本地文件和研究 commit。
- 代码、类型名、命令和配置字段不翻译；中文解释放在代码块后。

## 译文边界

34 个中文页都包含：逐节中文技术译文、原文章节对照、固定 commit 源链接，以及 byte-equivalent 的完整英文原文附录。原文代码、API 名称、命令、路径、JSON 字段不改写；代码块之后用中文解释输入、输出、状态和安全边界。原文若与当前实现有差异，页面会明确标出，不用文档猜测源码行为。

`translation-map.json` 是机器可读清单；[原文与中文文件映射](/reference/translation-map) 展示人工可读表格。
