## 中文译文

### Windows 上的 Bash 选择

Pi 默认使用 Git Bash。它按这个顺序寻找 shell：`~/.pi/agent/settings.json` 中的自定义路径、`C:\\Program Files\\Git\\bin\\bash.exe`、以及 PATH 上的 `bash.exe`（可能来自 Cygwin、MSYS2 或 WSL）。对多数用户，安装 Git for Windows 就足够。自定义路径只应指向你信任的 shell，不要把仓库内容直接当作 shell 配置。

### PowerShell Tool

可选的 `powershell` Tool 优先使用 `pwsh.exe`，否则使用 Windows PowerShell；启动参数是 `-NoProfile -NonInteractive -ExecutionPolicy Bypass`。管理员强制的 execution policy 仍可能优先于这些参数。要让模型使用 PowerShell 替代 model-facing `bash`，在 `defaultTools` 中写 `read`、`powershell`、`edit`、`write`；若要比较两者，可以同时列出 `bash` 和 `powershell`。编辑器里的 `!` 与 `!!` 命令仍使用 Bash，不会因 `defaultTools` 改变。

### Custom Bash Path

在 `~/.pi/agent/settings.json` 中配置 `shellPath`，值应是 JSON 字符串形式的 Windows 路径，例如 `C:\\cygwin64\\bin\\bash.exe`。JSON 的反斜杠需要转义；修改后重新启动 Pi 或按资源重新加载流程确认配置生效。

> 译者注：`defaultTools` 决定模型可以看到和调用的 Tool，`!`/`!!` 是编辑器命令路径；它们是两个不同的入口，所以只替换 `bash` 不会替换用户命令的 shell。

# Windows Setup

Pi uses Git Bash by default on Windows. Checked locations (in order):

1. Custom path from `~/.pi/agent/settings.json`
2. Git Bash (`C:\Program Files\Git\bin\bash.exe`)
3. `bash.exe` on PATH (Cygwin, MSYS2, WSL)

For most users, [Git for Windows](https://git-scm.com/download/win) is sufficient.

## PowerShell Tool

The optional `powershell` tool runs commands through `pwsh.exe` when available, otherwise Windows PowerShell. It starts PowerShell with `-NoProfile -NonInteractive -ExecutionPolicy Bypass`. Administrator-enforced execution policies can still take precedence.

Use `defaultTools` to replace the model-facing `bash` tool:

```json
{
  "defaultTools": ["read", "powershell", "edit", "write"]
}
```

Or enable both while comparing behavior:

```json
{
  "defaultTools": ["read", "bash", "powershell", "edit", "write"]
}
```

The `!` and `!!` editor commands still use Bash.

## Custom Bash Path

```json
{
  "shellPath": "C:\\cygwin64\\bin\\bash.exe"
}
```
