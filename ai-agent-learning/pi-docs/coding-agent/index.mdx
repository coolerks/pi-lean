## 中文译文

Pi 是一个保持核心精简的终端 Coding Agent。它不会把所有能力硬编码到核心，而是通过 TypeScript Extensions、Skills、Prompt Templates、Themes 和 Pi Packages 增加能力。下面的索引说明从安装到扩展、编程集成、平台设置和本地开发的完整路径。

### 快速开始

使用 npm 全局安装 `@earendil-works/pi-coding-agent` 时，示例明确加上 `--ignore-scripts`；这会关闭依赖的 lifecycle scripts，而普通 npm 安装不依赖它们。在 Linux 或 macOS 上，也可以使用 `https://pi.dev/install.sh` installer。卸载时要使用实际安装 Pi 的包管理器：npm、pnpm、Yarn 和 Bun 的命令不同。卸载 Pi 不会删除 `~/.pi/agent/` 下的 settings、credentials、sessions 和已安装 packages。

进入目标项目目录后运行 `pi`。认证有两条路径：启动后执行 `/login` 选择 subscription provider，或在启动前设置例如 `ANTHROPIC_API_KEY` 的 API-key provider。详细的认证、第一次 session 和常见问题见 [快速开始](/pi-docs/coding-agent/quickstart)。

### 从哪里开始

[快速开始](/pi-docs/coding-agent/quickstart) 负责安装和认证；[使用 Pi](/pi-docs/coding-agent/usage) 解释交互模式、斜杠命令、context files 和 CLI；[Providers](/pi-docs/coding-agent/providers) 解释订阅和 API keys；`llama.cpp` 章节解释本地 router。安全、容器化、Settings、Keybindings、Sessions 和 Compaction 分别处理权限边界、隔离、配置、快捷键、会话树和上下文压缩。

### 定制 Pi

Extensions 是宿主内的 TypeScript 模块，可以增加 tools、commands、events 和自定义 UI。Skills 是按需加载的能力说明；Prompt Templates 是可由斜杠命令展开的重复提示；Themes 改变终端显示；Pi Packages 将这些资源打包分发。Models 和 Custom Providers 则分别扩展模型定义与 API/OAuth 适配。它们的权限、加载范围和生命周期不同，不能把 Skill、Extension 和 MCP 当成同一种插件。

### 编程使用

SDK 让 Node.js 程序直接嵌入 Pi；RPC Mode 通过 stdin/stdout 的 JSONL 控制进程；JSON Event Stream Mode 输出机器可消费的结构化事件；TUI Components 提供 Extension 自定义终端 UI 的组件接口。RPC 是控制 Pi Agent 的协议，不能因为两者都使用 JSON 就把它和 MCP 混为一谈。

### Reference、平台与开发

Environment Variables 说明 Pi 进程配置以及 Bash Tool 可见的 session metadata；Session Format 说明 JSONL entries 和 `SessionManager` API。Windows、Termux、tmux、Terminal Setup 和 Shell Aliases 解决不同运行环境的终端边界。Development 章节最后说明本地 setup、项目结构、路径解析、调试命令和测试方式。

> 译者注：这个索引把 Pi 分成“运行核心”和“资源/扩展表面”。在 Java 中可以把 SDK/RPC 看成宿主 API，把 Extension loader 看成 SPI；在 Go 中则通常由显式 registry 和进程协议承担同样的边界。

# Pi Documentation

Pi is a minimal terminal coding harness. It is designed to stay small at the core while being extended through TypeScript extensions, skills, prompt templates, themes, and pi packages.

## Quick start

Install Pi with npm:

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
```

`--ignore-scripts` disables dependency lifecycle scripts during install. Pi does not require install scripts for normal npm installs.

On Linux or macOS, you can also use the installer:

```bash
curl -fsSL https://pi.dev/install.sh | sh
```

To uninstall pi itself, use npm for curl and npm installs:

```bash
npm uninstall -g @earendil-works/pi-coding-agent
```

For pnpm, Yarn, or Bun installs, use the matching global remove command: `pnpm remove -g @earendil-works/pi-coding-agent`, `yarn global remove @earendil-works/pi-coding-agent`, or `bun uninstall -g @earendil-works/pi-coding-agent`.

Then run it in a project directory:

```bash
pi
```

Authenticate with `/login` for subscription providers, or set an API key such as `ANTHROPIC_API_KEY` before starting pi.

For the full first-run flow, see [Quickstart](quickstart.md).
