## 中文译文

Pi 的 Shell Tool 以非交互方式运行 `bash -c`。这种 shell 默认不会展开 alias，所以你在交互式 shell 中定义的 alias 不会自动出现在 Pi 的命令环境里。

要启用 alias，在 `~/.pi/agent/settings.json` 配置 `shellCommandPrefix`。示例先执行 `shopt -s expand_aliases`，再用 `eval` 从 `~/.zshrc` 读取 alias 行；如果你使用 Bash 或其他 shell，应把路径改为对应的 `~/.bashrc` 等文件。前缀会影响 Pi 启动的 Shell Tool 命令，不等于把完整交互式 shell 配置无条件复制进每条命令。

执行前检查被读取配置文件的来源。不要从不受信任仓库的脚本中拼接 prefix，也不要让 alias 绕过 Tool 的 permission、timeout 或 output limit；alias 只是 shell 展开规则，不是 sandbox。

> 译者注：`shopt`、`eval` 和 alias 是 Bash 行为，不能直接搬到 PowerShell。跨平台配置应为不同 shell 分别定义 prefix，并用最小化的可信配置文件。

# Shell Aliases

Pi runs bash in non-interactive mode (`bash -c`), which doesn't expand aliases by default.

To enable your shell aliases, add to `~/.pi/agent/settings.json`:

```json
{
  "shellCommandPrefix": "shopt -s expand_aliases\neval \"$(grep '^alias ' ~/.zshrc)\""
}
```

Adjust the path (`~/.zshrc`, `~/.bashrc`, etc.) to match your shell config.
