# Go 15：组合 Harness

`harness.go` 的 `NewHarness` 创建 registry、教学级 PermissionPolicy、coding tools、Agent Loop、Session 和 Recorder。`Prompt` 读取 Session snapshot，把新 user message 追加到尾部，运行后立刻保存成功前缀，即使模型错误也保留已有历史。

这体现一个重要设计：组合层负责生命周期和持久化，Loop 只负责控制流。要达到 durable Harness，还需要把“接受 prompt”“Tool intent”“result entry”“terminal outcome”作为明确的 durable records，并在 crash/reopen 后按状态机恢复；设计见 [Harness 可靠性](/07-harness/reliability)。

## 验收

```bash
cd ai-agent-learning/examples/go-agent
```
